Evaluacion2 - GraphHopper

Descripción

Proyecto desarrollado para la Evaluación Parcial N.º 2 de la asignatura Telepresencia y Entornos Innovadores de Colaboración Humana (CUY6142).

El programa utiliza Python y la API de GraphHopper para calcular rutas entre dos ubicaciones.

Funcionalidades

Interfaz en español.

Distancias y duración con máximo dos decimales.

Instrucciones del recorrido en español.

Opción para salir escribiendo s o salir.

Requisitos

Python 3

Librerías requests y python-dotenv

Una API Key de GraphHopper

Instrucciones de ejecución

Descargar el repositorio.

Instalar las dependencias:
python -m pip install requests python-dotenv

Crear un archivo .env con la variable GRAPHHOPPER_API_KEY y su clave personal.

Ejecutar:
python graphhopper.py
